# Codex Quota Planner

![Codex Quota Planner 宣传图](./assets/codex-quota-planner-banner.png)

一个为 **Codex 用户**设计的个人额度规划器：单文件、零依赖、数据留在本机。

输入自己的剩余额度和重置时间，它会帮助你自主规划使用节奏：今天最多还能用多少，以及今晚至少应该保留多少。

> 这是社区工具，与 OpenAI 官方无隶属或背书关系。

## 为什么做它

额度规划看起来只是除法，真正容易出错的是“除以什么”。

最初按小时平均分配，会把睡觉时间也当成使用时间；只按自然日计算，又会把已经结束的夜间或周末当成可用时间。这个工具最终采用更贴近日常决策的口径：**只统计重置前仍有可用工作时段的日期。**

例如：

- 周一上午查看额度；
- 剩余额度是 90%；
- 周三下午重置。

额度需要覆盖周一、周二、周三三个工作日，因此每天 30%，周一结束时最低应剩 60%。晚上已经没有工作时段时，当天不会再占一份。

默认工作时段参考 DeepSeek 当前官方高峰期：北京时间周一至周五 `09:00–12:00`、`14:00–18:00`。其余时间和周末不计入。时段来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 原则

### 1. 计算口径服从真实生活

模型应该解释人的使用习惯，而不是让人迁就公式。睡觉、午休和周末不该被当成主要使用时段；只有重置前仍有工作时间可用的日期才分配额度。

### 2. 简单，但不能含糊

界面只回答两个核心问题：

- 今天最多可用多少？
- 今晚最低应剩多少？

同时公开“覆盖工作日”、采用的工作时段和计算公式，让结果可以被检查，而不是只给一个看似精确的数字。

### 3. 本地优先

没有账号、服务器、统计脚本或网络请求。输入通过浏览器的 `localStorage` 保存在本机；换浏览器、清理网站数据或移动文件后，记录可能无法继续读取。

### 4. 零安装、零构建

整个应用只有一个 `index.html`。不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 使用方法

1. 下载 [`index.html`](./index.html)。
2. 用 Edge、Chrome 或其他现代浏览器打开。
3. 输入当前剩余额度。
4. 二选一填写重置时间：
   - 输入还剩多少天、多少小时；
   - 直接选择重置日期和小时。

页面会自动获取当前时间并即时计算。再次打开同一文件时，会恢复上次输入。

## 计算规则

```text
覆盖工作日 = 从当前时刻到重置前，至少仍有一个工作时段可用的日期数
平均每工作日预算 = 当前剩余额度 ÷ 覆盖工作日
今日预算 = 今天仍有工作时段时取每日预算，否则为 0
今晚最低应剩 = 当前剩余额度 - 今日预算
```

默认工作时段为北京时间工作日 `09:00–12:00`、`14:00–18:00`。如果重置前已经没有工作时段，今日预算为 0%，今晚最低应保留全部剩余额度。重置时间必须晚于当前时间。

## 隐私

- 不联网；
- 不上传输入；
- 不使用 Cookie；
- 仅使用浏览器本地存储保存上次输入。
