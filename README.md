# Codex Quota Planner

![Codex Quota Planner 宣传图](./assets/codex-quota-planner-banner.png)

一个为 **Codex 用户**设计的个人额度规划器：单文件、零依赖、数据留在本机。

输入自己的剩余额度和重置时间，它会帮助你自主规划使用节奏：今天最多还能用多少，以及今晚至少应该保留多少。

> 这是社区工具，与 OpenAI 官方无隶属或背书关系。

## 为什么做它

额度规划看起来只是除法，真正容易出错的是“除以什么”。因此工具同时提供按使用份数和按剩余工作小时两种口径。

最初按小时平均分配，会把睡觉时间也当成使用时间；再根据当前时刻删掉今天，又会偏离“今天还剩多少额度”的规划目的。这个工具最终采用更直接的口径：**今天与中间日期各算一份，重置日已经进入的上午、下午工作时段各算一份。**

例如：

- 当前时间是 9 月 22 日 18:32；
- 剩余额度是 71%；
- 9 月 23 日 15:00 重置。

今天固定算 1 份；9 月 23 日上午算 1 份；15:00 已进入下午工作时段，再算 1 份。合计 3 份，每份约 23.67%，今晚最低应剩约 47.33%。

默认日内使用时段参考 DeepSeek 当前高峰：北京时间 `09:00–12:00`、`14:00–18:00`。默认每天都使用；也可以勾选“排除休息日”，按周六、周日排除。为保持离线和零依赖，法定节假日及调休不自动识别。时段来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 原则

### 1. 计算口径服从真实生活

模型应该解释人的规划方式，而不是让人迁就公式。当前已经几点不应抹掉今天已经存在的额度规划；重置日下午仍要工作，也应增加一份。是否排除周末由用户决定。

### 2. 简单，但不能含糊

界面只回答两个核心问题：

- 今天最多可用多少？
- 今晚最低应剩多少？

同时公开分配份数、剩余工时、每日明细和计算公式，让结果可以被检查，而不是只给一个看似精确的数字。

### 3. 本地优先

没有账号、服务器、统计脚本或网络请求。输入通过浏览器的 `localStorage` 保存在本机；换浏览器、清理网站数据或移动文件后，记录可能无法继续读取。

### 4. 零安装、零构建

整个应用只有一个 `index.html`。不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 使用方法

1. 下载 [`index.html`](./index.html)。
2. 用 Edge、Chrome 或其他现代浏览器打开。
3. 输入当前剩余额度。
4. 选择计算方式：
   - **工作日**：按今天、中间日期、重置日上午/下午的份数平均分配；
   - **小时工作日**：按今天剩余工作小时占全部剩余工作小时的比例分配。
5. 可选勾选“排除休息日”；离线版按周六、周日判断。
6. 二选一填写重置时间：
   - 输入还剩多少天、多少小时；
   - 直接选择重置日期和小时。

页面会自动获取当前时间并即时计算。再次打开同一文件时，会恢复上次输入。

## 计算规则

### 工作日模式

```text
规划份数 = 今天 1 份 + 中间日期每日期 1 份 + 重置日已开始的工作时段数
重置日 09:00 后增加上午 1 份，14:00 后再增加下午 1 份
平均每份预算 = 当前剩余额度 ÷ 规划份数
今日预算 = 平均每份预算
今晚最低应剩 = 当前剩余额度 - 今日预算
```

### 小时工作日模式

```text
全部剩余工时 = 每天 09:00–12:00、14:00–18:00 与“当前时刻到重置时刻”的重叠小时之和
今日额度占比 = 今天剩余工作小时 ÷ 全部剩余工作小时
今日预算 = 当前剩余额度 × 今日额度占比
今晚最低应剩 = 当前剩余额度 - 今日预算
```

默认时段为每天 `09:00–12:00`、`14:00–18:00`。工作日模式下，如果重置日在 09:00 或之前重置，该日增加 0 份；09:00 之后增加 1 份；14:00 之后增加 2 份。勾选“排除休息日”后，两种模式都会排除周六、周日。重置时间必须晚于当前时间。

## 隐私

- 不联网；
- 不上传输入；
- 不使用 Cookie；
- 仅使用浏览器本地存储保存上次输入。
