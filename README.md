# Codex Quota Planner

![Codex Quota Planner 宣传图](./assets/codex-quota-planner-banner.png)

一个为 **Codex 用户**设计的个人额度规划器：单文件、零依赖、数据留在本机。

输入自己的剩余额度和重置时间，它会帮助你自主规划使用节奏：今天最多还能用多少，以及今晚至少应该保留多少。

> 这是社区工具，与 OpenAI 官方无隶属或背书关系。

## 为什么做它

额度规划看起来只是除法，真正容易出错的是“除以什么”。

最初按小时平均分配，会把睡觉时间也当成使用时间；把办公高峰等同于全部使用时间，又会错误排除晚间。这个工具最终采用更贴近日常决策的口径：**只排除凌晨睡眠低谷，统计重置前仍有自然活跃时段的日期。**

例如：

- 今天上午查看额度；
- 剩余额度是 90%；
- 后天（周三）下午重置。

额度需要覆盖今天、明天和周三三个活跃日，因此每天 30%，今天结束时最低应剩 60%。晚上仍属于自然活跃时段，不会把今天错误排除。

默认自然活跃时段借用 DeepSeek 早期错峰优惠的作息口径：北京时间每天 `08:30–次日 00:30`；`00:30–08:30` 视为睡眠低谷。这里仅把历史时段作为个人使用习惯的启发式，不代表 DeepSeek 当前计费规则。历史时段参考：[腾讯云 DeepSeek API 文档](https://cloud.tencent.com/document/product/1772/117380)；DeepSeek 后续已宣布取消当时的夜间优惠：[DeepSeek-V3.1 发布](https://api-docs.deepseek.com/zh-cn/news/news250821/)。

## 原则

### 1. 计算口径服从真实生活

模型应该解释人的使用习惯，而不是让人迁就公式。凌晨睡眠不该被当成主要使用时段，但晚间和周末仍可能使用 Codex；只要当天仍有自然活跃时间，就应该分配额度。

### 2. 简单，但不能含糊

界面只回答两个核心问题：

- 今天最多可用多少？
- 今晚最低应剩多少？

同时公开“覆盖活跃日”、采用的活跃时段和计算公式，让结果可以被检查，而不是只给一个看似精确的数字。

### 3. 本地优先

没有账号、服务器、统计脚本或网络请求。输入通过浏览器的 `localStorage` 保存在本机；换浏览器、清理网站数据或移动文件后，记录可能无法继续读取。

### 4. 零安装、零构建

整个应用只有一个 `index.html`。不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 使用方法

1. 下载 [`index.html`](./index.html)。
2. 用 Edge、Chrome 或其他现代浏览器打开。
3. 输入当前剩余额度。
4. 二选一填写重置时间：
   - 输入还剩多少天、多少小时；
   - 直接选择重置日期和小时。

页面会自动获取当前时间并即时计算。再次打开同一文件时，会恢复上次输入。

## 计算规则

```text
覆盖活跃日 = 从当前时刻到重置前，至少仍有一段自然活跃时间可用的日期数
平均每活跃日预算 = 当前剩余额度 ÷ 覆盖活跃日
今日预算 = 今天仍有活跃时段时取每日预算，否则为 0
今晚最低应剩 = 当前剩余额度 - 今日预算
```

默认活跃时段为北京时间每天 `00:00–00:30`、`08:30–24:00`，等价于排除凌晨 `00:30–08:30`。如果重置前已经没有活跃时段，今日预算为 0%，今晚最低应保留全部剩余额度。重置时间必须晚于当前时间。

## 隐私

- 不联网；
- 不上传输入；
- 不使用 Cookie；
- 仅使用浏览器本地存储保存上次输入。
