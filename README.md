# Codex Quota Planner

![Codex Quota Planner 宣传图](./assets/codex-quota-planner-banner.png)

一个为 **Codex 用户**设计的个人额度规划器：单文件、零依赖、数据留在本机。

输入自己的剩余额度和重置时间，它会帮助你自主规划使用节奏：今天最多还能用多少，以及今晚至少应该保留多少。

> 这是社区工具，与 OpenAI 官方无隶属或背书关系。

## 为什么做它

额度规划看起来只是除法，真正容易出错的是“除以什么”。

最初按小时平均分配，会把睡觉时间也当成使用时间；再根据当前时刻删掉今天，又会偏离“今天还剩多少额度”的规划目的。这个工具最终采用更直接的口径：**今天固定计入，重置日根据日内使用时段决定是否计入，中间每个日期都计入。**

例如：

- 今天上午查看额度；
- 剩余额度是 90%；
- 后天（周三）下午重置。

额度需要覆盖今天、明天和周三三个规划日，因此每天 30%，今天结束时最低应剩 60%。当前已经几点不会把今天从规划中删除。

默认日内使用时段参考 DeepSeek 当前高峰：北京时间 `09:00–12:00`、`14:00–18:00`。DeepSeek 的计费规则会排除周末和节假日；本工具只借用一天中的时间段，并假设每天都使用，因此不排除任何日期。时段来源：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 原则

### 1. 计算口径服从真实生活

模型应该解释人的规划方式，而不是让人迁就公式。当前已经几点不应抹掉今天已经存在的额度规划；周末和节假日也按照相同的日内时段计算。

### 2. 简单，但不能含糊

界面只回答两个核心问题：

- 今天最多可用多少？
- 今晚最低应剩多少？

同时公开“覆盖规划日”、采用的日内时段和计算公式，让结果可以被检查，而不是只给一个看似精确的数字。

### 3. 本地优先

没有账号、服务器、统计脚本或网络请求。输入通过浏览器的 `localStorage` 保存在本机；换浏览器、清理网站数据或移动文件后，记录可能无法继续读取。

### 4. 零安装、零构建

整个应用只有一个 `index.html`。不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 使用方法

1. 下载 [`index.html`](./index.html)。
2. 用 Edge、Chrome 或其他现代浏览器打开。
3. 输入当前剩余额度。
4. 二选一填写重置时间：
   - 输入还剩多少天、多少小时；
   - 直接选择重置日期和小时。

页面会自动获取当前时间并即时计算。再次打开同一文件时，会恢复上次输入。

## 计算规则

```text
覆盖规划日 = 今天 + 中间日期 + 符合条件的重置日
重置日计入条件 = 重置时间晚于当天首个使用时段起点 09:00
平均每规划日预算 = 当前剩余额度 ÷ 覆盖规划日
今日预算 = 平均每规划日预算
今晚最低应剩 = 当前剩余额度 - 今日预算
```

默认时段为每天 `09:00–12:00`、`14:00–18:00`，包括周末和节假日。如果重置日在 09:00 或之前重置，该日不计入；09:00 之后重置则计入。重置时间必须晚于当前时间。

## 隐私

- 不联网；
- 不上传输入；
- 不使用 Cookie；
- 仅使用浏览器本地存储保存上次输入。
