# Codex Quota Planner

一个单文件、零依赖、数据留在本机的 Codex 额度规划器。

输入当前剩余额度和重置时间，它会告诉你：今天最多还能用多少，以及今晚至少应该保留多少。

> 这是社区工具，与 OpenAI 官方无隶属或背书关系。

## 为什么做它

额度规划看起来只是除法，真正容易出错的是“除以什么”。

最初按小时平均分配，会把睡觉时间也当成使用时间；按剩余 24 小时区间取整，又会把“今天”和“明天”错误地合并。这个工具最终采用更贴近日常决策的口径：**按重置前涉及的自然日平均分配，今天和重置日都计入。**

例如：

- 当前是 9 月 21 日；
- 剩余额度是 80%；
- 9 月 22 日 15:00 重置。

额度需要覆盖今天和明天两个自然日，因此每天 40%，今晚最低应剩 40%。重置发生在明天几点，不改变每日份额。

## 设计哲学

### 1. 计算口径服从真实生活

模型应该解释人的使用习惯，而不是让人迁就公式。睡觉时间不该被当成可用时段；跨过零点，就意味着进入了新的使用日。

### 2. 简单，但不能含糊

界面只回答两个核心问题：

- 今天最多可用多少？
- 今晚最低应剩多少？

同时公开“覆盖自然日”和计算公式，让结果可以被检查，而不是只给一个看似精确的数字。

### 3. 本地优先

没有账号、服务器、统计脚本或网络请求。输入通过浏览器的 `localStorage` 保存在本机；换浏览器、清理网站数据或移动文件后，记录可能无法继续读取。

### 4. 零安装、零构建

整个应用只有一个 `index.html`。不需要 Node.js，不需要安装依赖，也没有构建步骤。

## 使用方法

1. 下载 [`index.html`](./index.html)。
2. 用 Edge、Chrome 或其他现代浏览器打开。
3. 输入当前剩余额度。
4. 二选一填写重置时间：
   - 输入还剩多少天、多少小时；
   - 直接选择重置日期和小时。

页面会自动获取当前时间并即时计算。再次打开同一文件时，会恢复上次输入。

## 计算规则

```text
覆盖自然日 = 重置日期 - 今天日期 + 1
今日预算 = 当前剩余额度 ÷ 覆盖自然日
今晚最低应剩 = 当前剩余额度 - 今日预算
```

同一天重置算 1 天，明天重置算 2 天，后天重置算 3 天。重置时间必须晚于当前时间。

## 隐私

- 不联网；
- 不上传输入；
- 不使用 Cookie；
- 仅使用浏览器本地存储保存上次输入。
